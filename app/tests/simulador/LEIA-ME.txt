SIMULADOR PARA TESTES NO NAVEGADOR (uso do desenvolvimento)
Roda o app inteiro no Chromium com um Firebase simulado em memoria. Requisitos: Python 3, playwright (pip install playwright; playwright install chromium) e o SheetJS em /tmp/vendor/xlsx.full.min.js para os testes que importam planilhas.
Ajuste o caminho '/tmp/fb/' dentro de harness.py para a pasta onde estes arquivos estiverem.
  python3 baseline.py ../../public                      abre as telas e procura erros
  python3 t_features.py ../../public                    fluxos entre modulos, alertas, Curva S, auditoria
  python3 t_security.py ../../public                    permissoes, verificacao de e-mail, backup
  python3 t_nomes.py ../../public a.xlsx b.xlsx         nomes completos e fontes dos graficos
  python3 t_custos_cronograma.py ../../public a.xlsx    cabecalho congelado, vinculo ao orcamento, linha de base, MS Project, retencao, contrato, caixa
  python3 t_perfis_protecao.py ../../public             dados por obra, perfil Consulta, convite, App Check, restauracao semanal
O simulador NAO executa as regras do Firestore.
