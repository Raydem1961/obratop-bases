# Publicação automática (GitHub → Firebase Hosting)
1. Abra https://github.com/Raydem1961/obratop-bases/tree/main/entregas
2. Add file → Upload files → arraste o ZIP da nova versão → Commit changes.
3. Aba Actions: o fluxo "Publicar ObraTop" publica no Firebase (≈2 min).
4. No ObraTop, o aplicativo se atualiza sozinho (ou clique em "Atualizar aplicativo").
Chave de acesso: segredo FIREBASE_SERVICE_ACCOUNT do repositório (conta de serviço gh-deploy).
